# Mengenal Antarmuka

Aplikasi authenticated SisFour menggunakan shell responsif dengan sidebar, navbar, area konten, dashboard per experience, filter, tabel/list, modal, dan notifikasi.

## Pola umum

- **Sidebar** menampilkan menu yang tersedia untuk akun.
- **Dashboard** menonjolkan informasi dan aksi yang penting bagi role.
- **Filter Tahun Ajaran** digunakan pada surface periodik.
- **Search** mengutamakan nama, dengan identifier sebagai konteks sekunder.
- **Mobile** dapat mengubah tabel menjadi list/card tanpa mengubah hak akses.

# Tentang SisFour

SisFour adalah Sistem Informasi Manajemen MTsN 4 Jombang untuk kebutuhan akademik, presensi, monitoring, BK, UKS/Kesehatan, PTSP, Kartu Pelajar, personalia, pelaporan, dan self-service pengguna.

## Surface utama

- Website authenticated untuk pengguna internal.
- Public PTSP untuk layanan tanpa login sesuai kebutuhan.
- Public EWS Signage.
- API yang digunakan sesuai contract aplikasi.
- Android/Cordova pada tahap G4.

Manual ini berfokus pada penggunaan aplikasi, bukan konfigurasi teknis server.

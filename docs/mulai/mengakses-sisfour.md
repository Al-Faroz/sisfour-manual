# Mengakses SisFour

SisFour dapat digunakan melalui browser desktop/laptop dan browser mobile. Android/Cordova akan memakai pengalaman web yang sama sebagai dasar.

## Pilih surface yang tepat

| Kebutuhan | Surface |
|---|---|
| Pekerjaan internal | Web authenticated |
| Mengirim layanan PTSP tanpa akun | Public PTSP |
| Melihat monitor EWS publik | EWS Signage |
| Menggunakan Android | Aplikasi Cordova setelah G4 tersedia |

> [!IMPORTANT]
> Public PTSP dan Signage tidak berarti seluruh SisFour public. Modul internal tetap memerlukan authentication dan authorization.

## Sebelum membuka SisFour

<ul class="sf-checklist">
  <li>Gunakan browser modern seperti Chrome atau Edge.</li>
  <li>Pastikan koneksi jaringan stabil.</li>
  <li>Untuk fitur yang membutuhkan lokasi, izinkan geolocation hanya ketika aplikasi memintanya dan memang diperlukan.</li>
  <li>Gunakan perangkat pribadi atau logout setelah selesai pada perangkat bersama.</li>
</ul>

## Desktop atau mobile?

**Desktop/laptop** paling sesuai untuk administrasi berat seperti master data, matrix, bulk workflow, dan settings. **Mobile** diprioritaskan untuk role operasional seperti Pimpinan, BK, Guru/Wali, Siswa, Kesehatan, dan PTSP.

Alamat produksi resmi akan dicantumkan pada manual setelah environment publik dikunci.

## 23 September 2026

### M0 — Fondasi

- repository manual;
- VitePress;
- local search;
- theme dasar;
- CI build-only.

### M1 — Sitemap & Visual Shell

- sitemap target dikunci;
- navigasi Mulai / Role / Alur / Modul / Mobile / Bantuan;
- halaman role awal;
- landing modul;
- visual card/grid SisFour;
- tidak ada deployment GitHub Pages.

### M2 — Mulai + Role Guides

- halaman Mulai diperluas menjadi orientasi penggunaan;
- Login/Logout, Antarmuka, Tahun Ajaran, dan Hak Akses dijelaskan lebih operasional;
- panduan lengkap untuk Admin, Operator, Pimpinan, BK, Guru, Guru+Wali, Siswa, Kesehatan, dan PTSP;
- reusable flow/checklist/link components untuk halaman panduan;
- access boundary dan privacy constraint ditautkan ke pengalaman role;
- belum ada deployment GitHub Pages.

### M3 — Modul Inti Akademik

- Dashboard diperluas menjadi panduan current-state dan Quick Action;
- Master Data mendapat halaman canonical Guru, Pegawai, Siswa, Kelas, Tahun Ajaran, Mapel, Wali, dan Jadwal;
- Manajemen Siswa mendapat panduan Penempatan/Pindah, Kenaikan, Mutasi, Kelulusan, dan Restore;
- Presensi Siswa, Revisi Presensi, serta Jurnal Mengajar mendapat panduan langkah-per-langkah;
- Rekap Presensi, Matrix, Laporan Jurnal, dan EWS Internal mendapat halaman canonical;
- sidebar Modul diperluas sampai subhalaman M3;
- contract Presensi resmi vs exception Jurnal ditegaskan;
- belum ada deployment GitHub Pages.

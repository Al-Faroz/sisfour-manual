# Glosarium

## Istilah inti

**Role**  
Peran efektif akun seperti Admin, Operator, Pimpinan, BK, Guru, Siswa, Kesehatan, atau PTSP.

**Wali Kelas**  
Konteks Guru berdasarkan mapping pada Tahun Ajaran, bukan role terpisah.

**Scope**  
Batas data yang boleh diakses, misalnya seluruh data, kelas wali, kelas yang diampu, atau diri sendiri.

**Tahun Ajaran aktif**  
Periode default untuk banyak surface periodik.

**EWS**  
Early Warning System untuk menonjolkan exception yang memerlukan perhatian.

**Signage**  
Tampilan publik untuk monitoring ringkas tanpa membuka detail sensitif.

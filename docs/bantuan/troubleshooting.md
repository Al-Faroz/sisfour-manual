# Troubleshooting

Troubleshooting SisFour mengikuti pola aman: identifikasi konteks, cek permission/periode/scope, cek network/session, lalu verifikasi data sumber.

## Prinsip

1. Pastikan akun dan sesi masih aktif.
2. Pastikan Tahun Ajaran/filter sesuai.
3. Pastikan fitur memang tersedia untuk role/scope Anda.
4. Periksa pesan error atau empty state.
5. Jangan melakukan bypass permission atau mengubah data langsung di database untuk menyelesaikan masalah penggunaan biasa.

Kasus spesifik akan ditambahkan per modul.

# Panduan Pimpinan

Pimpinan menggunakan SisFour terutama untuk monitoring dan pengambilan keputusan, dengan karakter akses umumnya **read-only**.

## Prioritas dashboard

- exception KPI;
- tren singkat;
- EWS dan Catatan Pelanggaran;
- statistik umum.

Pimpinan dapat memiliki akses read-only/export pada domain tertentu, tetapi tidak memperoleh detail Konseling BK. Statistik hanya menampilkan agregat aman sesuai contract.

# Panduan BK

BK berfokus pada workflow pendampingan siswa dan monitoring EWS.

## Fokus utama

- Konseling dan tindak lanjut;
- Catatan Pelanggaran dan tindak lanjut;
- EWS;
- Prestasi;
- pencarian siswa;
- monitoring follow-up.

Konseling adalah data rahasia dan hanya tersedia pada access boundary yang sah.

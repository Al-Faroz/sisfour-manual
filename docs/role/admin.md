# Panduan Administrator

Administrator berfokus pada konfigurasi, master data, operasional lintas modul, dan kontrol sistem sesuai permission.

## Fokus utama

- Dashboard Admin
- Master Data dan Manajemen Siswa
- Pengaturan user/menu/sistem
- Operasional modul sesuai capability
- Backup, maintenance, dan log
- Statistik dan monitoring

Administrasi berat tetap paling nyaman dikerjakan pada desktop/laptop, walau UI tetap responsif.

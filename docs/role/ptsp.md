# Panduan PTSP

Role PTSP memakai identity Pegawai dan berfokus pada administrasi layanan PTSP.

## Dashboard PTSP

Dashboard memakai Tahun Ajaran aktif tanpa selector histori.

### KPI

- Layanan Baru;
- Layanan Diproses;
- Pengaduan Masuk;
- Rata-rata Kepuasan.

### Quick Action

- Layanan PTSP;
- Polling Kepuasan;
- Pengaduan;
- Buka Public PTSP.

## Alur kerja umum

<div class="sf-flow">
  <div><strong>Periksa permohonan masuk</strong>Buka Layanan dan Pengaduan terbaru.</div>
  <div><strong>Proses status</strong>Perbarui status hanya pada action yang memang tersedia.</div>
  <div><strong>Periksa Polling</strong>Gunakan data kepuasan sebagai ringkasan layanan.</div>
  <div><strong>Gunakan export bila diperlukan</strong>Export mengikuti capability internal PTSP.</div>
  <div><strong>Verifikasi public surface</strong>Public landing tetap terpisah dari administrasi authenticated.</div>
</div>

## Public PTSP

Public landing menyediakan tiga jalur besar:

1. Layanan PTSP;
2. Pengaduan;
3. Polling Kepuasan.

Pengaduan public bersifat anonim dan tidak meminta nama/kontak. Public submission tidak memberikan akses ke listing/detail internal.

## Bukti layanan

Setting cetak dapat mengatur Auto Print atau Auto Download PDF thermal 80 mm. Bila keduanya OFF, pengguna mendapat tombol Cetak Bukti setelah submit sukses. Tidak ada silent/background print.

## Privasi

Lampiran Pengaduan tidak mempunyai direct public URL. Statistik public PTSP hanya agregat dan tidak boleh membuka raw record atau PII.

# Panduan Operator

Operator berfokus pada administrasi harian dan pengelolaan data operasional sesuai permission.

## Fokus utama

- Master Data
- Manajemen Siswa
- Presensi dan laporan operasional
- Kartu Pelajar
- UKS/PTSP/BK bila permission terkait diberikan
- Export yang tersedia

Operator tidak otomatis memiliki semua capability Administrator.

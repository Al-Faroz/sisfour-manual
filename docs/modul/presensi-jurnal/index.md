# Presensi & Jurnal

## Presensi Siswa

- Sesi Awal
- Sesi Akhir
- input/bulk sesuai capability
- revisi presensi
- geofence/time rule bila berlaku

## Presensi Mengajar / Jurnal

- input jurnal
- exception siswa
- revisi
- atomic save

Presensi resmi siswa dan jurnal mengajar adalah dua domain data yang berbeda walaupun saling berkaitan dalam monitoring.

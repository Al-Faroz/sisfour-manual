# PTSP

PTSP memiliki dua surface: **public submission** dan **administrasi internal**.

## Public

- Landing PTSP
- Form Layanan
- Form Pengaduan anonim
- Form Polling Kepuasan
- Statistik publik agregat

## Internal

- Administrasi Layanan
- Administrasi Pengaduan
- Administrasi Polling
- Export
- Dashboard PTSP

Public submission tidak memberikan akses ke data internal.

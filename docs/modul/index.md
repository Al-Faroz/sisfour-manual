# Modul SisFour

Dokumentasi fitur akan dikelompokkan sesuai domain dan modul aplikasi.

## Modul utama

- Dashboard
- Master Data
- Akademik
- Presensi
- Jurnal Mengajar
- Laporan
- EWS
- Statistik & Signage
- BK
- Prestasi
- UKS / Kesehatan
- PTSP
- Kartu Pelajar
- Profil / Personalia
- Pengaturan / Maintenance / Backup / Log

Halaman modul akan disusun dari source dan SSOT aplikasi, kemudian diverifikasi terhadap UI aktual.

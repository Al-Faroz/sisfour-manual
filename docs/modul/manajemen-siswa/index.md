# Manajemen Siswa

Modul ini menangani perubahan status dan keanggotaan siswa sepanjang siklus akademik.

## Cakupan

- Penempatan / pindah kelas
- Kenaikan kelas
- Mutasi
- Kelulusan
- Restore lifecycle terminal bila capability tersedia

Proses lifecycle mempertahankan histori dan dijalankan secara transactional sesuai business rule aplikasi.

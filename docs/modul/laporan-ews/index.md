# Laporan dan EWS

Laporan akademik membaca data yang sudah tersimpan dan mempertahankan period context. Export mengikuti Tahun Ajaran yang sedang dipilih.

## Sumber resmi Presensi

Untuk Rekap, Matrix, dan EWS Presensi, sumber resmi adalah **Presensi Sesi Awal**.

Sesi Akhir dan exception siswa pada Jurnal tidak masuk perhitungan Presensi resmi.

## Aturan periodik

- initial filter = Tahun Ajaran aktif;
- Reset = Tahun Ajaran aktif;
- histori selectable bila domain mendukung;
- export mengikuti periode terpilih.

> [!NOTE]
> Laporan tidak boleh menganggap siswa Alpha hanya karena tidak ada record tanpa terlebih dahulu memperhitungkan membership/history periode tersebut.

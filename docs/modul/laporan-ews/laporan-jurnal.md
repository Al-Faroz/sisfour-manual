# Laporan Jurnal

Laporan Jurnal menampilkan **satu row untuk satu Jurnal**.

## Informasi utama

Satu entry dapat memuat:

- Tanggal;
- Guru / Kelas;
- Mapel / Jam / Sesi;
- Status Guru;
- Materi / Catatan;
- jumlah siswa S/I/A;
- aksi Detail.

Nama siswa exception tidak digandakan menjadi row utama. Detail siswa dimuat ketika diperlukan.

## Cara menggunakan

<div class="sf-flow">
  <div><strong>Pilih Tahun Ajaran</strong>Default adalah periode aktif.</div>
  <div><strong>Gunakan filter</strong>Pilih context Guru/Kelas/Mapel atau filter lain yang memang tersedia.</div>
  <div><strong>Baca listing</strong>Setiap row mewakili satu Jurnal.</div>
  <div><strong>Buka Detail</strong>Lihat daftar exception siswa bila jumlah S/I/A perlu diperiksa.</div>
  <div><strong>Export</strong>Jika capability tersedia, export mengikuti periode terpilih dan memuat Tahun Ajaran/Semester.</div>
</div>

## Mobile

Pada mobile, laporan operasional menggunakan card/adaptive presentation dan Detail dapat memakai modal scrollable/fullscreen pada layar sempit.

> [!NOTE]
> Jumlah S/I/A pada Laporan Jurnal adalah exception pembelajaran, bukan Presensi resmi sekolah.

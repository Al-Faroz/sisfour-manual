# Matrix Presensi

Matrix Presensi menampilkan pola Presensi resmi dalam bentuk dua dimensi untuk Tahun Ajaran yang dipilih.

## Sebelum membuka Matrix

- pastikan Tahun Ajaran benar;
- pahami bahwa sumber resmi adalah Sesi Awal;
- scope data mengikuti actor;
- membership historis digunakan untuk menentukan periode siswa.

## Cara menggunakan

<div class="sf-flow">
  <div><strong>Pilih Tahun Ajaran</strong>Initial dan Reset kembali ke periode aktif.</div>
  <div><strong>Atur filter yang tersedia</strong>Gunakan kelas atau context lain sesuai hak akses.</div>
  <div><strong>Muat Matrix</strong>Tunggu proses server menyelesaikan query periodik.</div>
  <div><strong>Baca pola per tanggal</strong>Gunakan Matrix untuk melihat distribusi kehadiran, bukan mengubah Presensi.</div>
  <div><strong>Export bila dibutuhkan</strong>Export mengikuti Tahun Ajaran yang sedang dipilih.</div>
</div>

## Export

Format utama export Presensi adalah XLSX. Semester Ganjil mencakup Juli–Desember, sedangkan Genap Januari–Juni.

Identifier seperti NISN diperlakukan sebagai text bila diperlukan agar digit tidak hilang di spreadsheet.

## Mobile

Matrix adalah salah satu surface administratif yang dapat menjadi exception layout karena sifat dua dimensinya. Gunakan desktop/laptop untuk pembacaan paling nyaman bila Matrix tidak dapat direduksi tanpa kehilangan fungsi.
